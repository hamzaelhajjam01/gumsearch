## 🚀 How to Install & Load in Chrome

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable **Developer mode** in the top right corner.
3. Click **Load unpacked**.
4. Select the `chrome-extension` folder inside this workspace:  
   `c:\Users\hp\OneDrive - Université Privée de Marrakech\Desktop\gumsearch\chrome-extension`
5. Visit any page on [Gumroad.com](https://gumroad.com) (e.g. `https://thomasfrank.gumroad.com/l/ultimate-brain`) to see the **GumSearch Intelligence Bar** live in action!
